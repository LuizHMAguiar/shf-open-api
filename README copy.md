# SistemaHospitalarFicticio-API

API de sistema hospitalar fictício desenvolvida com JSON Server.

## Disponibilidade
A API está disponível em https://shf-api.onrender.com/

## Instalação

### Pré-requisitos
- Node.js (v14 ou superior)
- npm

### Passos

1. Clone ou baixe o repositório
2. Instale as dependências:
```bash
npm install
```

## Execução

Para iniciar o servidor localmente:
```bash
npm start
```

O servidor será iniciado na **porta 3000** e exibirá:
```
✅ JSON Server está rodando na porta 3000
```

Acesse a API em: `http://localhost:3000`

## Características
- Banco de dados em JSON Server
- Apenas requisições GET são permitidas
- Resposta de erro padronizada para outros métodos HTTP
